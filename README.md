# Grand roue jeux télé

Un jeu de soirée sur téléphone : on fait tourner une roue de 12 jeux télé cultes, et Albatar l'avatar, un albatros marseillais en survêt, présente la partie à voix haute.

## Comment jouer

1. Ouvre `index.html` dans un navigateur (ou la page GitHub Pages du dépôt).
2. Choisis la formule : 4 joueurs ou 2 couples, puis entre les prénoms.
3. À ton tour, fais tourner la roue. Passe le téléphone à ton voisin : il lit la question et garde la réponse cachée.
4. Il touche « Gagné » ou « Raté » et les points s'ajoutent tout seuls.
5. « Fin de partie » affiche le podium.

## Les 12 jeux

Questions pour un champion, Motus, Qui veut gagner des millions ?, Le Juste Prix (version chiffres), N'oubliez pas les paroles, Fort Boyard, Attention à la marche !, Les Z'amours, Le Bigdil, Qui est qui ?, Slam, Burger Quiz (Sel ou poivre).

## Le présentateur

Albatar parle grâce à la synthèse vocale du navigateur. Le rendu dépend de la voix française installée sur l'appareil. Le bouton « Voix off » coupe le son.

Fait pour l'anniversaire de Cécile, le 28 septembre 2026.
